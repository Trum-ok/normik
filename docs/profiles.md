# Профили

Профиль адаптирует набор правил под требования кафедры без форка репозитория:
отключает правила, меняет их уровень, задаёт параметры.

```bash
nk check chapters --profile profiles/my-department.toml
```

Без ключа применяется встроенный профиль `base` — все правила с их
объявленными уровнями.

## Формат

```toml
name = "Кафедра N"
extends = "base"

# Отключить правила целиком.
disable = ["G732-6.5.1-reference-word"]

# Понизить уровень: нарушение показывается, но не влияет на код возврата.
[rules."G732-6.4.5-heading-depth"]
severity = "info"

# Поднять уровень.
[rules."G732-6.6.2-reference-word"]
severity = "error"

# Переопределить параметры. Незаданные берутся из объявления правила.
[rules."G732-5.3.2.1-keywords-count".params]
keywords_max = 20

# Наименования структурных элементов, принятые кафедрой вместо стандартных.
[elements.aliases]
"СПИСОК ЛИТЕРАТУРЫ" = "СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ"
```

| Ключ | Значение |
|---|---|
| `name` | имя профиля, попадает в шапку вывода |
| `extends` | имя встроенного профиля-основы; наследование на один уровень |
| `disable` | идентификаторы правил, которые не запускаются |
| `rules."ID".severity` | `error`, `warning` или `info` вместо объявленного |
| `rules."ID".params` | значения параметров правила |
| `elements.aliases` | наименования элементов кафедры и их наименования по стандарту |

Готовый образец для копирования —
[`profiles/example-university.toml`](https://github.com/Trum-ok/normik/blob/master/profiles/example-university.toml).

## Структурные элементы

Наименования элементов — общий словарь всех правил о структуре: состав, порядок,
регистр заголовков, содержание реферата. Если кафедра называет элемент иначе,
чем стандарт, наименование объявляется синонимом:

```toml
[elements.aliases]
"СПИСОК ЛИТЕРАТУРЫ" = "СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ"
"ОБОЗНАЧЕНИЯ И СОКРАЩЕНИЯ" = "ПЕРЕЧЕНЬ СОКРАЩЕНИЙ И ОБОЗНАЧЕНИЙ"
```

Слева — как пишет кафедра, справа — наименование по стандарту; регистр и знаки
препинания значения не имеют. Наименование справа проверяется: синоним, ведущий
к тому, чего в стандарте нет, — ошибка профиля, иначе опечатка молча выключала бы
опознание элемента.

Состав обязательных элементов задаётся параметрами правила
[`G732-4-required-element-missing`](rules/G732-4-required-element-missing.md).
Убрать одно требование, оставив остальные:

```toml
[rules."G732-4-required-element-missing".params]
excluded = ["РЕФЕРАТ"]
```

Задать перечень целиком:

```toml
[rules."G732-4-required-element-missing".params]
required = ["СОДЕРЖАНИЕ", "ВВЕДЕНИЕ", "ЗАКЛЮЧЕНИЕ", "СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ"]
```

В обоих списках наименования пишутся по стандарту либо синонимами кафедры.
Наименование, которого нет ни там ни там, проверку не выключает: элемент просто
не найдётся, и правило сообщит о его отсутствии — опечатка в профиле остаётся
видимой.

## Правила, выключенные по умолчанию

Часть правил даёт много находок, а требованием стандарта не является — такие
выключены по умолчанию и включаются явно:

```toml
enable = ["NK-STYLE-preposition-nbsp"]
```

На странице такого правила стоит пометка о том, что оно выключено. Ключ
`--select` тоже включает их: `nk check chapters --select NK-STYLE-preposition-nbsp`.

## Проверка профиля

Опечатка в идентификаторе правила — ошибка, а не молчаливое отключение
проверки: профиль, ссылающийся на несуществующее правило, не запускается.

Посмотреть, что получилось после наследования и переопределений:

```bash
nk profile show --profile profiles/my-department.toml
```

Команда печатает итоговый уровень каждого правила, состояние — включено или
отключено — и действующие параметры.

## Что настраивать имеет смысл

- **Требования кафедры расходятся со стандартом.** Например, принято сокращение
  «рис.» в ссылках: правило
  [`G732-6.5.1-reference-word`](rules/G732-6.5.1-reference-word.md)
  отключается.
- **Пороги.** Диапазон числа ключевых слов, предельная глубина рубрикации —
  параметры, а не константы.
- **Наименования и состав структурных элементов.** Кафедра пишет «СПИСОК
  ЛИТЕРАТУРЫ» или не требует реферата — это синонимы и `excluded`, а не
  отключение правила целиком.
- **Строгость сборки.** Уровень определяет, падает ли CI: `error` — да,
  `warning` и `info` — нет.

Параметры каждого правила перечислены на его странице в разделе
[Правила](rules/index.md).
