# text-quotes

**Прямые кавычки вместо «ёлочек».**

| | |
|---|---|
| Категория | Типографика |
| Источник требования | общее |
| Пункты | — |
| Уровень по умолчанию | <span class="nk-severity nk-severity--info">info</span> |
| Объявлено в | `nk.rules.typography.text_quotes` |
| Фикстуры | `tests/fixtures/text-quotes/` |
| Автоисправление | да, ключом `--fix` |

Находит прямую кавычку `"` в тексте отчёта.

## Почему это замечание

В русском наборе основные кавычки — «ёлочки». Прямая кавычка приходит из
редактора кода и в отчёте выглядит инородно.

## Как исправить

Заменить пару прямых кавычек на «ёлочки». Если кавычек на строке ровно две,
правка делается автоматически; в остальных случаях границы пары
определяются неоднозначно.

Сокращения babel — `"=`, `"|`, `"<`, `">` и подобные — правило не трогает:
это команды набора, а не кавычки.

## Нарушение

```latex
Структурный элемент "СОДЕРЖАНИЕ" начинают с новой страницы.
```

## Как правильно

```latex
Структурный элемент «СОДЕРЖАНИЕ» начинают с новой страницы.

\begin{lstlisting}
print("не кавычки отчёта")
\end{lstlisting}

Сокращения babel кавычками не считаются: Слова"=связки, набор"|без лигатуры.

Кавычки внутри буквальной вставки остаются как есть: \verb+значение "тут"+.
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["text-quotes"]

[rules."text-quotes"]
severity = "info"
```
