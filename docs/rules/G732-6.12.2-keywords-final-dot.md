# G732-6.12.2-keywords-final-dot

**Перечень ключевых слов заканчивается точкой.**

| | |
|---|---|
| Категория | Реферат |
| Пункты | ГОСТ 7.32-2017 п. 6.12.2 |
| Уровень по умолчанию | `error` |
| Объявлено в | `nk.rules.abstract.keywords_final_dot` |
| Фикстуры | `tests/fixtures/G732-6.12.2-keywords-final-dot/` |
| Автоисправление | да, ключом `--fix` |

Проверяет последний элемент перечня ключевых слов на точку в конце.

## Почему это нарушение

Перечень ключевых слов — не предложение: слова идут в строку через запятые,
и точка в конце не ставится.

## Как исправить

Убрать точку после последнего ключевого слова.

## Нарушение

```latex
\section*{РЕФЕРАТ}

КЛЮЧЕВЫЕ СЛОВА: ЛИНТЕР, ГОСТ, ОТЧЁТ, ОФОРМЛЕНИЕ, НОРМОКОНТРОЛЬ.
```

## Как правильно

```latex
\section*{РЕФЕРАТ}

КЛЮЧЕВЫЕ СЛОВА: ЛИНТЕР, ГОСТ, ОТЧЁТ, ОФОРМЛЕНИЕ, НОРМОКОНТРОЛЬ
```
