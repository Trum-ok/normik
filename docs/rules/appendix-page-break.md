# appendix-page-break

**Приложение не начинается с новой страницы.**

| | |
|---|---|
| Категория | Приложения |
| Пункты | ГОСТ 7.32-2017 п. 6.17.3<br>ГОСТ Р 2.105-2019 п. 6.3.4 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--error">error</span> |
| Объявлено в | `nk.rules.appendices.appendix_page_break` |
| Фикстуры | `tests/fixtures/appendix-page-break/` |
| Автоисправление | да, ключом `--fix` |

Проверяет разрыв страницы перед заголовком приложения.

## Почему это нарушение

Каждое приложение размещают с новой страницы. Заголовок, оформленный
через `\section*`, разрыва страницы сам не даёт ни в одном классе
документа — его ставят явно.

## Как исправить

Добавить `\newpage` перед заголовком приложения.

## Нарушение

```latex
\section*{ЗАКЛЮЧЕНИЕ}

Краткие выводы по результатам работы.

\section*{ПРИЛОЖЕНИЕ А}

Протоколы испытаний.
```

## Как правильно

```latex
\section*{ЗАКЛЮЧЕНИЕ}

Краткие выводы по результатам работы.

\newpage
\section*{ПРИЛОЖЕНИЕ А}

Протоколы испытаний.

\clearpage
\section*{ПРИЛОЖЕНИЕ Б}

Копии актов внедрения.
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["appendix-page-break"]

[rules."appendix-page-break"]
severity = "info"
```
