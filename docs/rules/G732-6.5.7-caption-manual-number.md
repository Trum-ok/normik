# G732-6.5.7-caption-manual-number

**Номер рисунка вписан в наименование вручную.**

| | |
|---|---|
| Категория | Иллюстрации |
| Пункты | ГОСТ 7.32-2017 п. 6.5.7 |
| Уровень по умолчанию | `error` |
| Объявлено в | `nk.rules.figures.figure_caption_manual_number` |
| Фикстуры | `tests/fixtures/G732-6.5.7-caption-manual-number/` |
| Автоисправление | да, ключом `--fix` |

Ищет наименования, начинающиеся со слова «Рисунок» или сокращения «Рис.»
с номером: номер вписан руками, хотя его формирует класс документа.

## Почему это нарушение

Слово «Рисунок», номер и тире подставляются автоматически. Вписанный руками
номер даёт в документе двойную подпись вида «Рисунок 3 — Рисунок 1 — Схема»
и расходится с автоматической нумерацией при вставке иллюстрации.

## Как исправить

Оставить в `\caption` только текст наименования, а ссылаться на рисунок
через метку.

## Нарушение

```latex
\begin{figure}
  \includegraphics{img/setup.png}
  \caption{Рисунок 1 — Схема экспериментальной установки}
  \label{fig:setup}
\end{figure}

\begin{figure}
  \includegraphics{img/plot.png}
  \caption{Рис. 2.1 - Зависимость погрешности}
  \label{fig:plot}
\end{figure}

\begin{figure}
  \includegraphics{img/app.png}
  \caption{Рисунок А.3 Общий вид стенда}
  \label{fig:app}
\end{figure}

\begin{figure}
  \includegraphics{img/inside.png}
  \caption{Рисунок 4 — Метка внутри подписи\label{fig:inside}}
\end{figure}
```

## Как правильно

```latex
\begin{figure}
  \includegraphics{img/setup.png}
  \caption{Схема экспериментальной установки}
  \label{fig:setup}
\end{figure}

Слово «рисунок» внутри наименования без номера нарушением не является.

\begin{figure}
  \includegraphics{img/plot.png}
  \caption{Рисунки серии А в сравнении с эталоном}
  \label{fig:plot}
\end{figure}
```
