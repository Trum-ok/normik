# terms-dash

**В перечне терминов определение отделено дефисом.**

| | |
|---|---|
| Категория | Термины и сокращения |
| Пункты | ГОСТ 7.32-2017 п. 6.14<br>ГОСТ Р 2.105-2019 п. 6.1.2 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--warning">warning</span> |
| Объявлено в | `nk.rules.terms.terms_dash` |
| Фикстуры | `tests/fixtures/terms-dash/` |
| Автоисправление | да, ключом `--fix` |

Проверяет знак, отделяющий термин от расшифровки.

## Почему это нарушение

Стандарт требует отделять правую часть тире. Дефис — другой знак, и в
наборе он заметно короче.

## Как исправить

Заменить дефис на тире.

## Нарушение

```latex
\section*{ТЕРМИНЫ И ОПРЕДЕЛЕНИЯ}

В настоящем отчёте о НИР применяют следующие термины с соответствующими
определениями.

нормоконтроль - проверка соблюдения норм и требований

\section*{ВВЕДЕНИЕ}
```

## Как правильно

```latex
\section*{ТЕРМИНЫ И ОПРЕДЕЛЕНИЯ}

В настоящем отчёте о НИР применяют следующие термины с соответствующими
определениями.

нормоконтроль — проверка соблюдения норм и требований

научно-исследовательская работа — работа, включающая исследования

\section*{ВВЕДЕНИЕ}

Дефис за пределами перечня терминов проверяется отдельным правилом: вот - такой.
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["terms-dash"]

[rules."terms-dash"]
severity = "info"
```
