# keywords-uppercase

**Ключевые слова набраны не прописными буквами.**

| | |
|---|---|
| Категория | Реферат |
| Пункты | ГОСТ 7.32-2017 п. 6.12.2 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--error">error</span> |
| Объявлено в | `nk.rules.abstract.keywords_uppercase` |
| Фикстуры | `tests/fixtures/keywords-uppercase/` |
| Автоисправление | да, ключом `--fix` |

Проверяет, что каждое ключевое слово набрано прописными буквами.

## Почему это нарушение

Ключевые слова приводят в именительном падеже прописными буквами, в строку,
через запятые — так они отделяются от остального текста реферата.

## Как исправить

Записать перечень прописными буквами. Регистр задаётся текстом, а не командой
оформления: `\MakeUppercase` в исходнике правило не увидит.

## Нарушение

```latex
\section*{РЕФЕРАТ}

КЛЮЧЕВЫЕ СЛОВА: линтер, ГОСТ, отчёт, оформление, нормоконтроль
```

## Как правильно

```latex
\section*{РЕФЕРАТ}

КЛЮЧЕВЫЕ СЛОВА: ЛИНТЕР, ГОСТ, ОТЧЁТ, ОФОРМЛЕНИЕ, НОРМОКОНТРОЛЬ
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["keywords-uppercase"]

[rules."keywords-uppercase"]
severity = "info"
```
