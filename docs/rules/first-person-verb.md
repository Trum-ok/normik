# first-person-verb

**Текст изложен от первого лица: глагол.**

| | |
|---|---|
| Категория | Изложение текста |
| Пункты | вне стандартов |
| Уровень по умолчанию | <span class="nk-severity nk-severity--warning">warning</span> |
| Объявлено в | `nk.rules.text.first_person_verb` |
| Фикстуры | `tests/fixtures/first-person-verb/` |
| Автоисправление | нет |

Ищет глаголы первого лица там, где местоимения нет: «Научился работать
с осциллографом», «считаю целесообразным». Прошедшее время берётся только
с начала предложения — лица оно не выражает, и опущенное подлежащее видно
лишь по началу фразы. Формулы, буквальные вставки и листинги не проверяются.

Авторское «мы» — «рассмотрим», «получим» — по умолчанию не трогается:
часть руководителей его требует. Включается параметром `plural`.

## Почему это замечание

Отчёт излагают безлично: сообщается, что сделано, а не кем. Опущенное «я»
от произнесённого не отличается — «Освоил методику измерений» остаётся
рассказом о себе.

## Как исправить

Переписать предложение безличной или страдательной конструкцией: «Освоил
методику измерений» → «методика измерений освоена», «считаю
целесообразным» → «целесообразно».

!!! note

    Готовое исправление правило не предлагает: оно принципиально неоднозначно.

## Параметры

| Параметр | По умолчанию |
|---|---|
| `plural` | `false` |

## Нарушение

```latex
Изучил структуру предприятия и его документооборот.
Научился работать с осциллографом.
Ознакомился с техникой безопасности на рабочем месте.
Считаю целесообразным доработать методику измерений.
```

## Как правильно

```latex
Структура предприятия и его документооборот изучены.
Работа с осциллографом освоена.
С техникой безопасности на рабочем месте проведено ознакомление.
Методику измерений целесообразно доработать.
Руководитель практики провёл инструктаж по охране труда.
Ниже рассмотрим устойчивость системы.
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["first-person-verb"]

[rules."first-person-verb"]
severity = "info"

[rules."first-person-verb".params]
plural = false
```
