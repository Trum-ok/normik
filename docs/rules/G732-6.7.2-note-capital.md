# G732-6.7.2-note-capital

**Слово «Примечание» набрано со строчной буквы.**

| | |
|---|---|
| Пункт ГОСТ 7.32-2017 | 6.7.2 |
| Уровень по умолчанию | `error` |
| Объявлено в | `nk.rules.elements.note_capital` |
| Фикстуры | `tests/fixtures/G732-6.7.2-note-capital/` |
| Автоисправление | да, ключом `--fix` |

Проверяет регистр слова, которым начинается примечание.

## Почему это нарушение

Слово «Примечание» — заголовок примечания, а не часть фразы: его печатают
с прописной буквы с абзацного отступа.

## Как исправить

Заменить первую букву на прописную. Листинги и таблицы правило не
просматривает: там это содержимое кода или ячейки.

## Нарушение

```latex
\begin{table}
  \caption{Результаты измерений}
  \begin{tabular}{ll}
    а & б \\
  \end{tabular}
\end{table}

примечание — Значения приведены с округлением до сотых.
```

## Как правильно

```latex
Примечание — Значения приведены с округлением до сотых.

Примечания

1 Первое замечание
2 Второе замечание

Слово в середине фразы правило не трогает: в примечании указан источник.

\begin{lstlisting}
примечание: кэш не используется
\end{lstlisting}
```
