# heading-hyphenation

**В заголовке задан перенос слова.**

| | |
|---|---|
| Категория | Заголовки и рубрикация |
| Пункты | ГОСТ 7.32-2017 п. 6.2.4, ГОСТ Р 2.105-2019 п. 6.6.2 |
| Уровень по умолчанию | `error` |
| Объявлено в | `nk.rules.headings.heading_hyphenation` |
| Фикстуры | `tests/fixtures/heading-hyphenation/` |
| Автоисправление | да, ключом `--fix` |

Ищет в заголовке заданную вручную точку переноса `\-`.

## Почему это нарушение

Переносы слов в заголовках не допускаются. Заданная точка переноса рано или
поздно срабатывает: при смене кегля, полей или редакции текста.

## Как исправить

Убрать `\-` из заголовка. Если строка не умещается, сократить заголовок либо
разбить его командой разрыва строки по границе слова.

## Нарушение

```latex
\section{Выбор направления экспе\-риментальных исследований}
```

## Как правильно

```latex
\section{Выбор направления экспериментальных исследований}

\subsection{Методы решения задач и их сравнительная оценка}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["heading-hyphenation"]

[rules."heading-hyphenation"]
severity = "info"
```
