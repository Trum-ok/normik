# enumeration-single-item

**В списке перечислений меньше двух элементов.**

| | |
|---|---|
| Категория | Перечисления |
| Пункты | ГОСТ Р 2.105-2019 п. 6.7.1 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--error">error</span> |
| Объявлено в | `nk.rules.enumerations.enumeration_single_item` |
| Фикстуры | `tests/fixtures/enumeration-single-item/` |
| Автоисправление | нет |

Считает элементы списка, не заглядывая во вложенные списки: у вложенного
свой счёт, и его проверяет отдельная находка на нём самом.

## Почему это нарушение

Список перечислений должен содержать не менее двух перечислений. Из одного
элемента список не образуется: перечислять нечего, и элемент оформляют
обычным абзацем.

## Как исправить

Дописать недостающие элементы либо развернуть единственный в текст абзаца.

!!! note

    Готовое исправление правило не предлагает: оно принципиально неоднозначно.

## Нарушение

```latex
\begin{itemize}
  \item удалённый заказ.
\end{itemize}
```

## Как правильно

```latex
Служба включает следующие модули:

\begin{itemize}
  \item удалённый заказ;
  \item виртуальный читальный зал.
\end{itemize}

Вложенный список считается отдельно:

\begin{enumerate}
  \item первый этап:
    \begin{itemize}
      \item подготовка;
      \item проверка.
    \end{itemize}
  \item второй этап.
\end{enumerate}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["enumeration-single-item"]

[rules."enumeration-single-item"]
severity = "info"
```
