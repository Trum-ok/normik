# formula-reference-format

**Номер формулы в ссылке приведён без скобок.**

| | |
|---|---|
| Категория | Формулы |
| Пункты | ГОСТ 7.32-2017 п. 6.8.4<br>ГОСТ Р 2.105-2019 п. 6.10.4 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--error">error</span> |
| Объявлено в | `nk.rules.formulas.formula_reference_format` |
| Фикстуры | `tests/fixtures/formula-reference-format/` |
| Автоисправление | да, ключом `--fix` |

Ищет ссылки на номер формулы, приведённые без скобок: «в формуле 1»,
«по формуле~\ref{eq:x}».

## Почему это нарушение

Ссылки на порядковые номера формул приводят в скобках: в формуле (1).
Номер без скобок сливается с текстом и не отличается от номера раздела.

## Как исправить

Взять номер в скобки. В LaTeX для этого есть `\eqref`: он подставляет
скобки сам.

## Нарушение

```latex
Погрешность вычисляется по формуле 1.
Итоговое значение получено по формуле~\ref{eq:total}.
```

## Как правильно

```latex
Погрешность вычисляется по формуле (1).
Итоговое значение получено по формуле~\eqref{eq:total}.

Слово «формула» без номера правило не трогает: расчёт по формуле приведён ниже.
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["formula-reference-format"]

[rules."formula-reference-format"]
severity = "info"
```
