# structural-heading-numbered

**Заголовок структурного элемента пронумерован.**

| | |
|---|---|
| Категория | Заголовки и рубрикация |
| Источник требования | стандарт |
| Пункты | ГОСТ 7.32-2017 п. 6.2.1 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--error">error</span> |
| Объявлено в | `nk.rules.headings.structural_heading_numbered` |
| Фикстуры | `tests/fixtures/structural-heading-numbered/` |
| Автоисправление | да, ключом `--fix` |

Ищет заголовки структурных элементов, заданные нумерованной формой команды
раздела.

## Почему это нарушение

Порядковые номера имеют только разделы основной части. Пронумерованное
введение сдвигает нумерацию всех последующих разделов и попадает в содержание
как раздел 1.

## Как исправить

Использовать ненумерованную форму команды — со звёздочкой — и добавить элемент
в содержание вручную, если этого требует класс документа. Если заголовок набран
макросом шаблона, правку вносят в объявление макроса, а не в текст отчёта.

## Нарушение

```latex
\section{ВВЕДЕНИЕ}

\section{ЗАКЛЮЧЕНИЕ}

\section{СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ}
```

## Как правильно

```latex
\section*{ВВЕДЕНИЕ}

\section*{ЗАКЛЮЧЕНИЕ}

\section*{СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ}

Разделы основной части, наоборот, нумеруются.

\section{Выбор направления исследований}

\subsection{Методы решения задач}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["structural-heading-numbered"]

[rules."structural-heading-numbered"]
severity = "info"
```
