# terms-opening

**Перечень терминов не начинается с установленной фразы.**

| | |
|---|---|
| Категория | Термины и сокращения |
| Источник требования | стандарт |
| Пункты | ГОСТ 7.32-2017 п. 5.5.2<br>ГОСТ Р 2.105-2019 п. 6.1.2 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--error">error</span> |
| Объявлено в | `nk.rules.terms.terms_opening` |
| Фикстуры | `tests/fixtures/terms-opening/` |
| Автоисправление | нет |

Ищет в теле перечня терминов и определений вводную фразу — строку со словами
«применяют следующие термины», без учёта регистра.

## Почему это нарушение

Перечень терминов открывается фразой, оговаривающей, что определения действуют
в пределах этого отчёта. Определения без такой оговорки читаются как претензия
на общеупотребительность.

## Как исправить

Поставить первой строкой после заголовка фразу «В настоящем отчёте о НИР
применяют следующие термины с соответствующими определениями.».

## Нарушение

```latex
\section*{ТЕРМИНЫ И ОПРЕДЕЛЕНИЯ}

нормоконтроль — проверка соблюдения норм и требований

\section*{ВВЕДЕНИЕ}
```

## Как правильно

```latex
\section*{ТЕРМИНЫ И ОПРЕДЕЛЕНИЯ}

В настоящем отчёте о НИР применяют следующие термины с соответствующими
определениями.

нормоконтроль — проверка соблюдения норм и требований

\section*{ВВЕДЕНИЕ}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["terms-opening"]

[rules."terms-opening"]
severity = "info"
```
