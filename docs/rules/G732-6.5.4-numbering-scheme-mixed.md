# G732-6.5.4-numbering-scheme-mixed

**Схема нумерации иллюстраций задана в документе несколько раз.**

| | |
|---|---|
| Категория | Иллюстрации |
| Пункт ГОСТ 7.32-2017 | 6.5.4 |
| Уровень по умолчанию | `error` |
| Объявлено в | `nk.rules.figures.numbering_scheme_mixed` |
| Фикстуры | `tests/fixtures/G732-6.5.4-numbering-scheme-mixed/` |
| Автоисправление | нет |

Проверяет, что схема нумерации иллюстраций объявлена один раз.

## Почему это нарушение

Иллюстрации нумеруют либо сквозной нумерацией, либо в пределах раздела.
Переопределение схемы посреди отчёта означает, что часть рисунков получит
номера одного вида, а часть — другого, и ссылки перестанут быть однозначными.

## Как исправить

Оставить одно объявление схемы в преамбуле и убрать остальные.

## Нарушение

```latex
\counterwithin{figure}{section}

\section{Методика}

\begin{figure}
  \includegraphics{img/setup.png}
  \caption{Схема установки}
\end{figure}

\renewcommand{\thefigure}{\arabic{figure}}

\section{Результаты}

\begin{figure}
  \includegraphics{img/plot.png}
  \caption{Зависимость погрешности}
\end{figure}
```

## Как правильно

```latex
\counterwithin{figure}{section}

\section{Методика}

\begin{figure}
  \includegraphics{img/setup.png}
  \caption{Схема установки}
\end{figure}

\section{Результаты}

\begin{figure}
  \includegraphics{img/plot.png}
  \caption{Зависимость погрешности}
\end{figure}

Схема нумерации таблиц объявляется отдельно и правило о рисунках не трогает.

\counterwithin{table}{section}
```
