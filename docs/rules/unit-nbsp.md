# unit-nbsp

**Число не привязано к единице измерения.**

| | |
|---|---|
| Категория | Типографика |
| Источник требования | вне стандартов |
| Пункты | ГОСТ Р 2.105-2019 п. 6.16.6 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--info">info</span> |
| Объявлено в | `nk.rules.typography.unit_nbsp` |
| Фикстуры | `tests/fixtures/unit-nbsp/` |
| Автоисправление | да, ключом `--fix` |

Находит обычный пробел между числом и следующей за ним единицей или сокращением.

## Почему это замечание

Перенос, оставляющий число в конце строки, а единицу в начале следующей,
читается как ошибка набора. Особенно заметно в сведениях об объёме отчёта,
где чисел и сокращений много подряд.

## Как исправить

Поставить неразрывный пробел: `45~с.`, `12~%`, `5~мм`.

Одиночное «с» без точки правило не проверяет: «таблица 2 с результатами»
от секунд по тексту не отличить.

!!! note

    Требование нужно под любым стандартом, а пункт назван там, где оно записано: область правила пункт не сужает.

## Нарушение

```latex
Отчёт 45 с., 3 рис., 2 табл., 12 источн., 1 прил.
Погрешность не превысила 12 \%, зазор составил 5 мм.
```

## Как правильно

```latex
Отчёт 45~с., 3~рис., 2~табл., 12~источн., 1~прил.
Погрешность не превысила 12~\%, зазор составил 5~мм.

Слово целиком единицей не является: 45 страниц, 5 миллиметров.

Одиночное «с» без точки правило не проверяет: таблица 2 с результатами.
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["unit-nbsp"]

[rules."unit-nbsp"]
severity = "info"
```
