# math-sign-without-value

**Математический знак приведён без числового значения.**

| | |
|---|---|
| Категория | Изложение текста |
| Пункты | ГОСТ Р 2.105-2019 п. 5.2.4 |
| Уровень по умолчанию | `warning` |
| Объявлено в | `nk.rules.text.math_sign_without_value` |
| Фикстуры | `tests/fixtures/math-sign-without-value/` |
| Автоисправление | нет |

Ищет знаки величин в тексте и смотрит, есть ли рядом число. Формулы,
таблицы и буквальные вставки не проверяются: там знак — часть записи,
а не замена слову. Знак «равно» правило не ищет: в тексте он почти всегда
часть формулы, а та уже вырезана.

## Почему это нарушение

В тексте документа математические знаки величин без числовых значений не
применяют: «> допустимого» читается как обрывок формулы, а «больше
допустимого» — как фраза.

## Как исправить

Заменить знак словом либо дописать числовое значение, к которому он
относится.

## Нарушение

```latex
Отклонение не должно быть > допустимого.
Погрешность \% от измеренного значения.
Комплект поставляется по чертежу № основного исполнения.
```

## Как правильно

```latex
Отклонение не должно быть больше допустимого.
Погрешность 5~\% от измеренного значения.
Комплект поставляется по чертежу № 12 основного исполнения.
Диапазон измерения $x > 5$ проверяется на стенде.
Массовая доля составляет не менее 99,4~\%.
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["math-sign-without-value"]

[rules."math-sign-without-value"]
severity = "info"
```
