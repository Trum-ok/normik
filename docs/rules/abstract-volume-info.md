# abstract-volume-info

**В реферате нет сведений об объёме отчёта.**

| | |
|---|---|
| Категория | Реферат |
| Пункты | ГОСТ 7.32-2017 п. 5.3.2 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--error">error</span> |
| Объявлено в | `nk.rules.abstract.abstract_volume_info` |
| Фикстуры | `tests/fixtures/abstract-volume-info/` |
| Автоисправление | нет |

Ищет в реферате сведения об объёме — число со словом «с.», например «45 с.».
Проверяется только их наличие: сверить число страниц с настоящим объёмом по
исходникам нельзя.

## Почему это нарушение

Реферат открывается сведениями об объёме отчёта, числе книг, иллюстраций,
таблиц, использованных источников и приложений. Это первое, по чему читающий
оценивает работу, и составляется оно по готовому документу.

## Как исправить

Добавить первой строкой реферата строку вида
«Отчёт 45 с., 1 кн., 3 рис., 2 табл., 12 источн., 1 прил.».

## Нарушение

```latex
\section*{РЕФЕРАТ}

КЛЮЧЕВЫЕ СЛОВА: ЛИНТЕР, ГОСТ, ОТЧЁТ, ОФОРМЛЕНИЕ, ПРОВЕРКА

Объектом исследования является процесс нормоконтроля.

\section*{ВВЕДЕНИЕ}
```

## Как правильно

```latex
\section*{РЕФЕРАТ}

Отчёт 45 с., 1 кн., 3 рис., 2 табл., 12 источн., 1 прил.

КЛЮЧЕВЫЕ СЛОВА: ЛИНТЕР, ГОСТ, ОТЧЁТ, ОФОРМЛЕНИЕ, ПРОВЕРКА

Объектом исследования является процесс нормоконтроля.

\section*{ВВЕДЕНИЕ}

% Тот же реферат, где правка типографики связала числа с единицами.
\section*{РЕФЕРАТ}

Отчёт 45~с., 3~рис., 2~табл., 10~источн.
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["abstract-volume-info"]

[rules."abstract-volume-info"]
severity = "info"
```
