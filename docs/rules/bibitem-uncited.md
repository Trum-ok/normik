# bibitem-uncited

**На запись списка источников нет ссылок в тексте.**

| | |
|---|---|
| Категория | Источники и ссылки на них |
| Пункты | ГОСТ 7.32-2017 п. 6.16, ГОСТ Р 2.105-2019 п. 6.4.2 |
| Уровень по умолчанию | `warning` |
| Объявлено в | `nk.rules.bibliography.bibliography_uncited` |
| Фикстуры | `tests/fixtures/bibitem-uncited/` |
| Автоисправление | нет |

Ищет записи списка источников, на которые в тексте нет ни одной ссылки.

## Почему это нарушение

Список содержит источники, использованные при составлении отчёта. Запись,
на которую нет ссылки, использованной не является и к тому же ломает
нумерацию по порядку упоминания.

## Как исправить

Сослаться на источник в тексте либо убрать запись из списка.

## Нарушение

```latex
Методика изложена в \cite{ivanov}.

\begin{thebibliography}{9}
  \bibitem{ivanov} Иванов И. И. Методика измерений. Москва, 2020. 120 с.
  \bibitem{petrov} Петров П. П. Обработка результатов. Москва, 2021. 200 с.
\end{thebibliography}
```

## Как правильно

```latex
Методика изложена в \cite{ivanov}, обработка результатов — в \cite{petrov},
поправки — в работе \emph{\cite{sidorov}}\footnote{Подробнее см. \cite{kuznetsov}.}.

\begin{thebibliography}{9}
  \bibitem{ivanov} Иванов И. И. Методика измерений. Москва, 2020. 120 с.
  \bibitem{petrov} Петров П. П. Обработка результатов. Москва, 2021. 200 с.
  \bibitem{sidorov} Сидоров С. С. Поправки к методике. Москва, 2022. 80 с.
  \bibitem{kuznetsov} Кузнецов К. К. Замечания к поправкам. Москва, 2023. 40 с.
\end{thebibliography}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["bibitem-uncited"]

[rules."bibitem-uncited"]
severity = "info"
```
