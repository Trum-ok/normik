# sign-instead-of-word

**Знак приведён вместо слова.**

| | |
|---|---|
| Категория | Изложение текста |
| Источник требования | стандарт |
| Пункты | ГОСТ Р 2.105-2019 п. 5.2.4 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--warning">warning</span> |
| Объявлено в | `nk.rules.text.sign_instead_of_word` |
| Фикстуры | `tests/fixtures/sign-instead-of-word/` |
| Автоисправление | нет |

Ищет минус, плюс и знак диаметра в тексте. Формулы, таблицы и буквальные
вставки не проверяются: там знак — часть записи. Дефис между словами и тире
между числами правило не трогает: знаком величины они не являются.

## Почему это нарушение

В тексте документа математический знак перед значением величины заменяют
словом: «минус 40» не спутать с переносом или с тире, а «-40» — можно.

## Как исправить

Написать слово: «минус 40», «плюс 10», «диаметр 20».

## Нарушение

```latex
Испытания проводят при температуре -40 градусов Цельсия.
Допуск составляет +10 единиц шкалы.
Отверстие ⌀20 просверлено насквозь.
```

## Как правильно

```latex
Испытания проводят при температуре минус 40 градусов Цельсия.
Допуск составляет плюс 10 единиц шкалы.
Отверстие диаметром 20~мм просверлено насквозь.
Приведён расчёт по формуле $y = -40 x$.
Изделие-2 испытано отдельно.
Диапазон 5--10 единиц проверен полностью.
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["sign-instead-of-word"]

[rules."sign-instead-of-word"]
severity = "info"
```
