# unit-in-series

**Единица величины повторена при каждом значении ряда.**

| | |
|---|---|
| Категория | Изложение текста |
| Пункты | ГОСТ Р 2.105-2019 п. 6.16.4 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--warning">warning</span> |
| Объявлено в | `nk.rules.text.unit_in_series` |
| Фикстуры | `tests/fixtures/unit-in-series/` |
| Автоисправление | нет |

Ищет два соседних значения одной и той же единицы, разделённых запятой или
точкой с запятой. Значения с разными единицами рядом нарушением не являются:
ряда они не образуют.

## Почему это нарушение

Если ряд значений выражен в одной единице, её указывают только после
последнего значения: повтор при каждом числе удлиняет запись, ничего
к ней не добавляя.

## Как исправить

Убрать единицу у всех значений ряда, кроме последнего: «1,50; 1,75; 2,00 м».

!!! note

    Готовое исправление правило не предлагает: оно принципиально неоднозначно.

## Нарушение

```latex
Толщина ленты составляет 1,50 мм; 1,75 мм; 2,00 мм.
Масса образцов равна 5 кг, 7 кг.
```

## Как правильно

```latex
Толщина ленты составляет 1,50; 1,75; 2,00~мм.
Масса образцов равна 5 и 7~кг.
Габариты составляют 5~мм, 7~кг и 3~Вт по отдельным параметрам.
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["unit-in-series"]

[rules."unit-in-series"]
severity = "info"
```
