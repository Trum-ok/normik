# G732-6.4.6-enumeration-letters

**В перечислении использована недопустимая буква.**

| | |
|---|---|
| Категория | Перечисления |
| Пункты | ГОСТ 7.32-2017 п. 6.4.6 |
| Уровень по умолчанию | `error` |
| Объявлено в | `nk.rules.enumerations.enumeration_letters` |
| Фикстуры | `tests/fixtures/G732-6.4.6-enumeration-letters/` |
| Автоисправление | нет |

Проверяет буквенные обозначения элементов перечисления, заданные явно —
`\item[а)]` и подобные.

## Почему это нарушение

Элементы перечисления обозначают строчными буквами русского алфавита начиная
с «а», пропуская ё, з, й, о, ч, ъ, ы и ь: они неотличимы от других букв или
от цифр в мелком кегле.

## Как исправить

Заменить букву на следующую допустимую по порядку и сдвинуть обозначения
остальных элементов перечисления.

## Нарушение

```latex
\begin{enumerate}
  \item[а)] удалённый заказ;
  \item[ё)] виртуальная справочная служба;
  \item[з)] виртуальный читальный зал.
\end{enumerate}
```

## Как правильно

```latex
\begin{enumerate}
  \item[а)] удалённый заказ;
  \item[б)] виртуальная справочная служба;
  \item[в)] виртуальный читальный зал.
\end{enumerate}

\begin{itemize}
  \item удалённый заказ;
  \item виртуальная справочная служба.
\end{itemize}
```
