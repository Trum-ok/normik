# enumeration-lowercase

**Элемент перечисления начат с прописной буквы.**

| | |
|---|---|
| Категория | Перечисления |
| Источник требования | стандарт |
| Пункты | ГОСТ Р 2.105-2019 п. 6.7.1 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--warning">warning</span> |
| Объявлено в | `nk.rules.enumerations.enumeration_lowercase` |
| Фикстуры | `tests/fixtures/enumeration-lowercase/` |
| Автоисправление | нет |

Смотрит первую букву текста элемента на той строке, где он начат.

Стандарт разрешает прописную букву там, где она обязательна для первого
слова, а имя собственное от обычного слова по исходникам не отличить.
Аббревиатуру правило пропускает — слово целиком прописными не проверяется, —
но «Москва» в начале элемента даст ложное срабатывание. Поэтому правило
выключено по умолчанию.

## Почему это нарушение

Элементы перечисления продолжают вводную формулировку, а не начинают новое
предложение: прописная буква разрывает эту связь.

## Как исправить

Заменить первую букву на строчную либо, если слово требует прописной,
оставить как есть и отключить правило.

!!! note

    Правило выключено по умолчанию. Включается профилем:

    ```toml
    enable = ["enumeration-lowercase"]
    ```

!!! note

    Готовое исправление правило не предлагает: оно принципиально неоднозначно.

## Нарушение

```latex
\begin{itemize}
  \item Удалённый заказ;
  \item виртуальный читальный зал.
\end{itemize}
```

## Как правильно

```latex
Служба включает следующие модули:

\begin{itemize}
  \item удалённый заказ;
  \item АЦП с разрешением 12 бит;
  \item виртуальный читальный зал.
\end{itemize}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["enumeration-lowercase"]

[rules."enumeration-lowercase"]
severity = "info"
```
