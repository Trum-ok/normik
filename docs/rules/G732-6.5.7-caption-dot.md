# G732-6.5.7-caption-dot

**Наименование рисунка заканчивается точкой.**

| | |
|---|---|
| Пункт ГОСТ 7.32-2017 | 6.5.7 |
| Уровень по умолчанию | `error` |
| Объявлено в | `nk.rules.elements.figure_caption_dot` |
| Фикстуры | `tests/fixtures/G732-6.5.7-caption-dot/` |
| Автоисправление | да, ключом `--fix` |

Проверяет наименование рисунка на точку в конце. Точка внутри наименования
нарушением не является.

## Почему это нарушение

Наименование рисунка приводят с прописной буквы без точки в конце: оно
образует с номером единую подпись, а не предложение.

## Как исправить

Убрать точку в конце `\caption`.

## Нарушение

```latex
\section{Методика}

Схема установки приведена на рисунке 1.

\begin{figure}[h]
  \centering
  \includegraphics[width=0.8\textwidth]{img/setup.png}
  \caption{Схема экспериментальной установки.}
\end{figure}

Результаты измерений показаны на рисунке 2.

\begin{figure}
  \includegraphics{img/plot.png}
  \caption{Зависимость погрешности от числа
    измерений.}
\end{figure}

\begin{figure}
  \includegraphics{img/inside.png}
  \caption{Метка внутри подписи.\label{fig:inside}}
\end{figure}
```

## Как правильно

```latex
\section{Методика}

Схема установки приведена на рисунке 1.

\begin{figure}[h]
  \centering
  \includegraphics[width=0.8\textwidth]{img/setup.png}
  \caption{Схема экспериментальной установки}
\end{figure}

Наименование из двух строк точкой тоже не заканчивается.

\begin{figure}
  \includegraphics{img/plot.png}
  \caption{Зависимость погрешности от числа
    измерений}
\end{figure}

Точка внутри наименования нарушением не является.

\begin{figure}
  \includegraphics{img/scheme.png}
  \caption{Схема стенда, вариант 2.1, общий вид}
\end{figure}

Подпись таблицы проверяется отдельным правилом по п. 6.6.3.

\begin{table}
  \caption{Результаты измерений.}
  \begin{tabular}{ll}
    а & б \\
  \end{tabular}
\end{table}

\begin{figure}
  \includegraphics{img/inside.png}
  \caption{Метка внутри подписи\label{fig:inside}}
\end{figure}
```
