# bibitem-url-access-date

**У электронного адреса нет даты обращения.**

| | |
|---|---|
| Категория | Источники и ссылки на них |
| Источник требования | стандарт |
| Пункты | ГОСТ Р 7.0.100-2018 п. 5.8.6.4 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--error">error</span> |
| Объявлено в | `nk.rules.bibliography.bibitem_url_access_date` |
| Фикстуры | `tests/fixtures/bibitem-url-access-date/` |
| Автоисправление | нет |

Проверяет, что за электронным адресом идут сведения о дате обращения:
фраза «дата обращения», число, месяц и год в круглых скобках. Для
электронного журнала вместо неё приводят дату публикации — такая запись
правилом принимается. Записи разбираются только в списке, набранном
в исходнике: у списка, собираемого BibTeX, описаний в `.tex` нет.

## Почему это нарушение

Сетевой ресурс меняется и исчезает, поэтому описание указывает, каким его
видел автор отчёта. Без даты обращения ссылка не проверяется: непонятно,
на какое состояние страницы она указывает.

## Как исправить

Дописать после адреса дату, когда ресурс открывали:
`URL: http://example.ru (дата обращения: 04.09.2026)`

## Нарушение

```latex
Источник приведён в \cite{site}.

\begin{thebibliography}{9}
  \bibitem{site} Библиотека : официальный сайт. – Москва, 2024. –
  URL: https://www.rsl.ru/.
  \bibitem{portal} Портал открытых данных. – Москва, 2023. –
  URL: https://data.gov.ru/ (дата обращения 04.09.2026).
\end{thebibliography}
```

## Как правильно

```latex
Источник приведён в \cite{site}.

\begin{thebibliography}{9}
  \bibitem{site} Библиотека : официальный сайт. – Москва, 2024. –
  URL: https://www.rsl.ru/ (дата обращения: 04.09.2026).
  \bibitem{journal} Вестник МГТУ : электронный журнал. – Москва, 2021. –
  URL: https://vestnik.bmstu.ru/. – Дата публикации: 21.04.2021.
  \bibitem{ivanov} Иванов, И.~И. Методика измерений. – Москва : Наука, 2020. – 120~с.
\end{thebibliography}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["bibitem-url-access-date"]

[rules."bibitem-url-access-date"]
severity = "info"
```
