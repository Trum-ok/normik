# particle-nbsp

**Частица не привязана к предыдущему слову.**

| | |
|---|---|
| Категория | Типографика |
| Пункты | вне стандартов |
| Уровень по умолчанию | `info` |
| Объявлено в | `nk.rules.typography.particle_nbsp` |
| Фикстуры | `tests/fixtures/particle-nbsp/` |
| Автоисправление | да, ключом `--fix` |

Находит частицу «же», «бы» или «ли», отделённую от предыдущего слова.

## Почему это замечание

В отличие от предлога, эти частицы примыкают к слову слева: в конце строки
не должно оставаться слово, от которого частицу оторвал перенос. Поэтому
неразрывный пробел ставится перед частицей, а не после неё.

## Как исправить

Поставить неразрывный пробел слева: `отличался~бы`, `так~ли`.

## Нарушение

```latex
Если бы методика была иной, результат отличался бы существенно.
Автор же указывает, что данные проверены; так ли это, неизвестно.
```

## Как правильно

```latex
Если~бы методика была иной, результат отличался~бы существенно.
Автор~же указывает, что данные проверены; так~ли это, неизвестно.

Частица внутри слова нарушением не является: также, тоже, если, или.

Предлоги привязывают к следующему слову, ими занимается отдельное правило.
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["particle-nbsp"]

[rules."particle-nbsp"]
severity = "info"
```
