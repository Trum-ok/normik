# appendix-order

**Приложения идут не в порядке ссылок на них.**

| | |
|---|---|
| Категория | Приложения |
| Пункты | ГОСТ 7.32-2017 п. 6.17.2<br>ГОСТ Р 2.105-2019 п. 6.3.3 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--error">error</span> |
| Объявлено в | `nk.rules.appendices.appendix_order` |
| Фикстуры | `tests/fixtures/appendix-order/` |
| Автоисправление | нет |

Сопоставляет порядок приложений с порядком первых упоминаний вида
«в приложении А» в тексте. Упоминания внутри самих приложений не считаются:
ссылка одного приложения на другое порядок не задаёт. Приложение, на которое
ссылок нет, порядок не нарушает — его разбирает отдельное правило. Работает
только на полном документе.

## Почему это нарушение

Приложения располагают в порядке ссылок на них: читатель, дойдя до первой
ссылки, находит нужное приложение первым, а не листает их все подряд.

## Как исправить

Переставить приложения в порядке первых ссылок и переобозначить их буквами
подряд либо изменить порядок изложения в основной части.

## Нарушение

```latex
\begin{document}

Копии актов внедрения приведены в приложении Б, протоколы испытаний — в приложении А.

\newpage
\section*{ПРИЛОЖЕНИЕ А}

Протоколы испытаний.

\newpage
\section*{ПРИЛОЖЕНИЕ Б}

Копии актов внедрения.

\end{document}
```

## Как правильно

```latex
\begin{document}

Протоколы испытаний приведены в приложении А, копии актов — в приложении Б.

\newpage
\section*{ПРИЛОЖЕНИЕ А}

Протоколы испытаний. Форма акта показана в приложении Б: ссылка изнутри
приложения порядка не задаёт.

\newpage
\section*{ПРИЛОЖЕНИЕ Б}

Копии актов внедрения.

\newpage
\section*{ПРИЛОЖЕНИЕ В}

Приложение без ссылки разбирается другим правилом.

\end{document}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["appendix-order"]

[rules."appendix-order"]
severity = "info"
```
