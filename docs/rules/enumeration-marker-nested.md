# enumeration-marker-nested

**Элемент маркированного списка разбит на подсписок.**

| | |
|---|---|
| Категория | Перечисления |
| Пункты | ГОСТ Р 2.105-2019 п. 6.7.4 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--error">error</span> |
| Объявлено в | `nk.rules.enumerations.enumeration_marker_nested` |
| Фикстуры | `tests/fixtures/enumeration-marker-nested/` |
| Автоисправление | нет |

Ищет список, вложенный непосредственно в маркированный. Находка выдаётся
на вложенный список: именно он показывает, что верхний уровень пора
обозначить.

## Почему это нарушение

Уровни списка различают по обозначению элемента. Маркер обозначения не
даёт, поэтому при разбиении на подсписок верхний уровень перестаёт
читаться: непонятно, к какому элементу относится вложенный список.

## Как исправить

Обозначить элементы верхнего уровня буквами или номерами со скобкой —
в LaTeX заменить внешний `itemize` на `enumerate`.

!!! note

    Готовое исправление правило не предлагает: оно принципиально неоднозначно.

## Нарушение

```latex
\begin{itemize}
  \item подготовка, включающая:
    \begin{itemize}
      \item выбор оборудования;
      \item расчёт нагрузки.
    \end{itemize}
  \item проведение испытаний.
\end{itemize}
```

## Как правильно

```latex
Работы разбиты на этапы:

\begin{enumerate}
  \item[а)] подготовка, включающая:
    \begin{itemize}
      \item выбор оборудования;
      \item расчёт нагрузки.
    \end{itemize}
  \item[б)] проведение испытаний.
\end{enumerate}

Плоский маркированный список подсписков не имеет:

\begin{itemize}
  \item масса изделия;
  \item габариты.
\end{itemize}
```
