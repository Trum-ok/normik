# figure-reference-word

**В ссылке на иллюстрацию использовано сокращение «рис.».**

| | |
|---|---|
| Категория | Иллюстрации |
| Источник требования | стандарт |
| Пункты | ГОСТ 7.32-2017 п. 6.5.1<br>ГОСТ Р 2.105-2019 п. 6.9.3 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--warning">warning</span> |
| Объявлено в | `nk.rules.figures.figure_reference_word` |
| Фикстуры | `tests/fixtures/figure-reference-word/` |
| Автоисправление | нет |

Ищет в тексте сокращение «рис.» перед номером или ссылкой.

## Почему это нарушение

При ссылке пишут слово «рисунок» полностью и его номер: сокращение в ссылке
не применяется.

## Как исправить

Заменить «рис.» на «рисунок» в нужном падеже. Если на кафедре сокращение
принято, правило отключается профилем.

## Нарушение

```latex
Схема установки приведена на рис. 1.
Результаты измерений показаны на рис.~\ref{fig:plot}.
```

## Как правильно

```latex
Схема установки приведена на рисунке 1.
Результаты измерений показаны на рисунке~\ref{fig:plot}.

Сокращение без номера правило не трогает: рис. в имени файла img/рис.png.
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["figure-reference-word"]

[rules."figure-reference-word"]
severity = "info"
```
