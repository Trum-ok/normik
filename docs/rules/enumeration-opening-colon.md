# enumeration-opening-colon

**Перед списком перечислений нет вводной формулировки с двоеточием.**

| | |
|---|---|
| Категория | Перечисления |
| Пункты | ГОСТ Р 2.105-2019 п. 6.7.1 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--error">error</span> |
| Объявлено в | `nk.rules.enumerations.enumeration_opening` |
| Фикстуры | `tests/fixtures/enumeration-opening-colon/` |
| Автоисправление | нет |

Смотрит ближайшую непустую строку выше `\begin` списка и проверяет двоеточие
в её конце. Строка с `\item` подходит: вложенный список вводит текст своего
элемента.

## Почему это нарушение

Список перечислений относится к формулировке, которая его вводит: без неё
читающий не знает, что именно перечисляется. Двоеточие в конце этой
формулировки и связывает её со списком.

## Как исправить

Дописать перед списком фразу, которая относится ко всему списку, и
закончить её двоеточием.

!!! note

    Готовое исправление правило не предлагает: оно принципиально неоднозначно.

## Нарушение

```latex
\begin{itemize}
  \item удалённый заказ;
  \item виртуальный читальный зал.
\end{itemize}
```

## Как правильно

```latex
Служба включает следующие модули:

\begin{itemize}
  \item удалённый заказ;
  \item виртуальный читальный зал.
\end{itemize}

Этапы работ:

\begin{enumerate}
  \item подготовка, включающая:
    \begin{itemize}
      \item выбор оборудования;
      \item расчёт нагрузки.
    \end{itemize}
  \item проведение испытаний.
\end{enumerate}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["enumeration-opening-colon"]

[rules."enumeration-opening-colon"]
severity = "info"
```
