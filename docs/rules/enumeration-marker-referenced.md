# enumeration-marker-referenced

**На элемент маркированного списка дана ссылка.**

| | |
|---|---|
| Категория | Перечисления |
| Источник требования | стандарт |
| Пункты | ГОСТ Р 2.105-2019 п. 6.7.4 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--error">error</span> |
| Объявлено в | `nk.rules.enumerations.enumeration_marker_reference` |
| Фикстуры | `tests/fixtures/enumeration-marker-referenced/` |
| Автоисправление | нет |

Ищет метки внутри маркированного списка, на которые в тексте есть `\ref`.
Метка без ссылки нарушением не является: сослаться ещё не значит сослаться.

## Почему это нарушение

Маркер не даёт элементу обозначения, а сослаться можно только на
обозначенный элемент: ссылка «см. перечисление» не говорит, на какое.
Список, элементы которого упоминают в тексте, оформляют буквами или
номерами со скобкой.

## Как исправить

Заменить маркированный список на буквенный или числовой — в LaTeX это
`enumerate` с нужным обозначением элементов.

!!! note

    Готовое исправление правило не предлагает: оно принципиально неоднозначно.

## Нарушение

```latex
\begin{itemize}
  \item точность измерения\label{req:accuracy};
  \item время отклика.
\end{itemize}

Условие~\ref{req:accuracy} проверяется на стенде.
```

## Как правильно

```latex
Требования перечислены ниже:

\begin{enumerate}
  \item[а)] точность измерения\label{req:accuracy};
  \item[б)] время отклика.
\end{enumerate}

Условие~\ref{req:accuracy} проверяется на стенде.

На этот элемент ссылок нет, метка оставлена про запас:

\begin{itemize}
  \item масса изделия\label{req:mass};
  \item габариты.
\end{itemize}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["enumeration-marker-referenced"]

[rules."enumeration-marker-referenced"]
severity = "info"
```
