# G732-6.7.4-footnote-space

**Знак сноски отделён пробелом от поясняемого слова.**

| | |
|---|---|
| Пункт ГОСТ 7.32-2017 | 6.7.4 |
| Уровень по умолчанию | `error` |
| Объявлено в | `nk.rules.elements.footnote_space` |
| Фикстуры | `tests/fixtures/G732-6.7.4-footnote-space/` |
| Автоисправление | да, ключом `--fix` |

Проверяет, что сноска стоит вплотную к слову, к которому относится.

## Почему это нарушение

Знак сноски ставят без пробела непосредственно после слова, числа или
символа, к которому даётся пояснение. Пробел отрывает знак от слова
и в наборе выглядит как отдельный символ.

## Как исправить

Убрать пробел перед `\footnote`.

## Нарушение

```latex
Методика заимствована из отраслевого руководства \footnote{Ссылка на источник.}

Команда пробела отрывает знак сноски так же, как обычный пробел\ \footnote{Второй источник.}
```

## Как правильно

```latex
Методика заимствована из отраслевого руководства\footnote{Ссылка на источник.}

Сноска в начале строки правило не трогает: перенос сюда пробела не добавляет.

Знак сноски после разрыва строки и так начинает новую строку:\\ \footnote{Третий источник.}
```
