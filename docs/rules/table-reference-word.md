# table-reference-word

**В ссылке на таблицу использовано сокращение «табл.».**

| | |
|---|---|
| Категория | Таблицы |
| Пункты | ГОСТ 7.32-2017 п. 6.6.2, ГОСТ Р 2.105-2019 п. 6.8.3 |
| Уровень по умолчанию | `warning` |
| Объявлено в | `nk.rules.tables.table_reference_word` |
| Фикстуры | `tests/fixtures/table-reference-word/` |
| Автоисправление | нет |

Ищет в тексте сокращение «табл.» перед номером или ссылкой.

## Почему это нарушение

При ссылке пишут слово «таблица» полностью и её номер.

## Как исправить

Заменить «табл.» на «таблица» в нужном падеже.

## Нарушение

```latex
Результаты приведены в табл. 1.
Сводка по этапам дана в табл.~\ref{tab:summary}.
```

## Как правильно

```latex
Результаты приведены в таблице 1.
Сводка по этапам дана в таблице~\ref{tab:summary}.
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["table-reference-word"]

[rules."table-reference-word"]
severity = "info"
```
