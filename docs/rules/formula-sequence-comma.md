# formula-sequence-comma

**Формулы идут подряд без разделяющего знака.**

| | |
|---|---|
| Категория | Формулы |
| Источник требования | стандарт |
| Пункты | ГОСТ Р 2.105-2019 п. 6.10.1 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--warning">warning</span> |
| Объявлено в | `nk.rules.formulas.formula_sequence_comma` |
| Фикстуры | `tests/fixtures/formula-sequence-comma/` |
| Автоисправление | нет |

Ищет соседние выключные формулы, между которыми в исходнике нет текста,
и проверяет знак в конце первой из них. Формулы, разделённые пояснением или
любым другим текстом, правило не трогает.

## Почему это нарушение

Формулы, следующие одна за другой и не разделённые текстом, разделяют
запятой: иначе они читаются как одна разорванная формула.

## Как исправить

Поставить запятую в конце первой формулы, перед закрывающей командой
окружения.

!!! note

    Готовое исправление правило не предлагает: оно принципиально неоднозначно.

## Нарушение

```latex
\begin{equation}
    \rho = \frac{m}{V}
\end{equation}
\begin{equation}
    V = a b c
\end{equation}
```

## Как правильно

```latex
Плотность и объём вычисляют по формулам

\begin{equation}
    \rho = \frac{m}{V},
\end{equation}
\begin{equation}
    V = a b c.
\end{equation}

Формулы, разделённые текстом, знака между собой не требуют:

\begin{equation}
    E = m c^2
\end{equation}

где $m$~--- масса тела.

\begin{equation}
    p = m v
\end{equation}
```
