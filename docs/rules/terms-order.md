# terms-order

**Термины в перечне идут не по алфавиту.**

| | |
|---|---|
| Категория | Термины и сокращения |
| Пункты | ГОСТ 7.32-2017 п. 6.14 |
| Уровень по умолчанию | `error` |
| Объявлено в | `nk.rules.terms.terms_order` |
| Фикстуры | `tests/fixtures/terms-order/` |
| Автоисправление | нет |

Сравнивает термины перечня между собой по алфавиту. Записью считается строка
с определением справа от тире, поэтому вводная фраза перечня в сравнение
не попадает. Регистр не различается, «ё» приравнивается к «е». Термины
на латинице сравниваются между собой, а не с русскими: переход к латинскому
алфавиту нарушением не считается.

## Почему это нарушение

Перечень терминов ведут по алфавиту: он нужен для справок, а искать в нём
подряд, как в связном тексте, никто не будет.

## Как исправить

Переставить запись выше — на то место, которое ей отводит алфавит.

## Нарушение

```latex
\section*{ТЕРМИНЫ И ОПРЕДЕЛЕНИЯ}

В настоящем отчёте о НИР применяют следующие термины с соответствующими
определениями.

нормоконтроль — проверка соблюдения норм и требований

верификация — подтверждение соответствия установленным требованиям

\section*{ВВЕДЕНИЕ}
```

## Как правильно

```latex
\section*{ТЕРМИНЫ И ОПРЕДЕЛЕНИЯ}

В настоящем отчёте о НИР применяют следующие термины с соответствующими
определениями.

верификация — подтверждение соответствия установленным требованиям

Ёмкость — количественная характеристика накопителя

нормоконтролёр — должностное лицо, выполняющее нормоконтроль

нормоконтроль — проверка соблюдения норм и требований

diffusion — процесс переноса вещества

\section*{ВВЕДЕНИЕ}

За пределами перечня алфавит не проверяется: яблоко — плод, абрикос — плод.
```
