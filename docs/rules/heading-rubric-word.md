# heading-rubric-word

**Заголовок начинается со слова «глава» или «раздел».**

| | |
|---|---|
| Категория | Заголовки и рубрикация |
| Источник требования | положение вуза |
| Пункты | — |
| Уровень по умолчанию | <span class="nk-severity nk-severity--warning">warning</span> |
| Объявлено в | `nk.rules.headings.heading_rubric_word` |
| Фикстуры | `tests/fixtures/heading-rubric-word/` |
| Автоисправление | да, ключом `--fix` |

Ищет заголовки, начатые словом, которое называет саму рубрику. Заголовки
структурных элементов не проверяются: «ПРИЛОЖЕНИЕ А» — их собственное
наименование, а не рубрика основной части.

Ни один из стандартов такого запрета не содержит, поэтому правило выключено
по умолчанию. Включают его профилем того вуза, чьё положение этого требует.

## Почему это нарушение

Что перед читающим раздел, видно по номеру и по месту заголовка. Слово
«Раздел» в самом заголовке повторяет номер и отнимает место у наименования.

## Как исправить

Убрать слово рубрики из заголовка, оставив наименование.

!!! note

    Правило выключено по умолчанию. Включается профилем:

    ```toml
    enable = ["heading-rubric-word"]
    ```

!!! note

    Ни один стандарт этого не требует: источник — положение вуза либо методические указания кафедры. Название источника и пункт объявляет [профиль](../profiles.md#стандарт-и-свой-источник-требований).

## Нарушение

```latex
\section{Глава 1. Обзор существующих решений}

\subsection{Раздел 1.1 Постановка задачи}
```

## Как правильно

```latex
\section{Обзор существующих решений}

\subsection{Постановка задачи}

\section*{ПРИЛОЖЕНИЕ А}

\section{Разделение выборки на обучающую и контрольную}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["heading-rubric-word"]

[rules."heading-rubric-word"]
severity = "info"
```
