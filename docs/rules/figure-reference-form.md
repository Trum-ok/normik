# figure-reference-form

**Ссылка на графический материал дана не установленным оборотом.**

| | |
|---|---|
| Категория | Иллюстрации |
| Пункты | вне стандартов |
| Уровень по умолчанию | `warning` |
| Объявлено в | `nk.rules.figures.figure_reference_form` |
| Фикстуры | `tests/fixtures/figure-reference-form/` |
| Автоисправление | нет |

Ищет упоминание рисунка с номером или `\ref` и смотрит, стоит ли перед ним
оборот «в соответствии с». Сокращение «рис.» считается упоминанием наравне
с полным словом: о нём сообщает отдельное правило, но оборот оно не заменяет.
Подписи внутри окружений рисунка не проверяются: там номер часть
наименования, а не ссылка.

Ни один из стандартов оборота не предписывает, поэтому правило выключено
по умолчанию. Включают его профилем того вуза, чьё положение этого требует.

## Почему это нарушение

Положение вуза может задавать единственную форму ссылки на графический
материал. Разнобой оборотов в одной работе читается как небрежность,
а нормоконтроль его возвращает.

## Как исправить

Переписать ссылку установленным оборотом: «в соответствии с рисунком 2».

!!! note

    Правило выключено по умолчанию. Включается профилем:

    ```toml
    enable = ["figure-reference-form"]
    ```

!!! note

    Готовое исправление правило не предлагает: оно принципиально неоднозначно.

## Нарушение

```latex
Зависимость показана на рисунке~\ref{fig:speed}.
Схема установки приведена на рисунке 2.
Общий вид дан на рис. 3.
```

## Как правильно

```latex
Зависимость линейна в соответствии с рисунком~\ref{fig:speed}.
Схема установки приведена в соответствии с рисунком 2.
Общий вид дан в соответствии с рис. 3.

\begin{figure}
  \includegraphics{plot.png}
  \caption{Зависимость скорости от нагрузки}
  \label{fig:speed}
\end{figure}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["figure-reference-form"]

[rules."figure-reference-form"]
severity = "info"
```
