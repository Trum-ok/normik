# G732-6.17.4-appendix-letter

**Приложение обозначено недопустимой буквой.**

| | |
|---|---|
| Категория | Приложения |
| Пункты | ГОСТ 7.32-2017 п. 6.17.4 |
| Уровень по умолчанию | `error` |
| Объявлено в | `nk.rules.appendices.appendix_letter` |
| Фикстуры | `tests/fixtures/G732-6.17.4-appendix-letter/` |
| Автоисправление | нет |

Проверяет букву в заголовке вида «ПРИЛОЖЕНИЕ А»: она должна быть одной прописной
буквой кириллицы из допустимого набора.

Набор допустимых обозначений задаётся [профилем](../profiles.md#обозначения-приложений):
у другого источника требований он свой.

## Почему это нарушение

Приложения обозначают буквами русского алфавита начиная с А. Ё, З, Й, О, Ч, Ъ, Ы
и Ь пропускаются: они плохо различимы в качестве обозначения.

## Как исправить

Заменить обозначение на ближайшее допустимое, сдвинув при необходимости
обозначения следующих приложений.

## Нарушение

```latex
\section*{ПРИЛОЖЕНИЕ Ё}

\section*{ПРИЛОЖЕНИЕ З}

\section*{ПРИЛОЖЕНИЕ 1}
```

## Как правильно

```latex
\section*{ПРИЛОЖЕНИЕ А}

\section*{ПРИЛОЖЕНИЕ Б}

\section*{ПРИЛОЖЕНИЕ В}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["G732-6.17.4-appendix-letter"]

[rules."G732-6.17.4-appendix-letter"]
severity = "info"
```
