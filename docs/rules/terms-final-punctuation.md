# terms-final-punctuation

**Запись перечня терминов заканчивается знаком препинания.**

| | |
|---|---|
| Категория | Термины и сокращения |
| Источник требования | стандарт |
| Пункты | ГОСТ 7.32-2017 п. 6.14<br>ГОСТ Р 2.105-2019 п. 6.1.2 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--warning">warning</span> |
| Объявлено в | `nk.rules.terms.terms_final_punctuation` |
| Фикстуры | `tests/fixtures/terms-final-punctuation/` |
| Автоисправление | да, ключом `--fix` |

Проверяет последний знак записи перечня терминов. Вводная фраза перечня
записью не считается: разделителя в ней нет.

## Почему это нарушение

Список терминологических статей располагают столбцом без знаков препинания
в конце: запись — не предложение, и точка или точка с запятой в её конце
сбивают ритм столбца.

## Как исправить

Убрать знак препинания в конце записи.

## Нарушение

```latex
В отчёте применяют следующие термины:

АЦП — аналого-цифровой преобразователь;
СКО — среднеквадратическое отклонение.
```

## Как правильно

```latex
\section*{ТЕРМИНЫ И ОПРЕДЕЛЕНИЯ}

В отчёте применяют следующие термины:

АЦП — аналого-цифровой преобразователь
СКО — среднеквадратическое отклонение
ЭВМ — электронно-вычислительная машина
```
