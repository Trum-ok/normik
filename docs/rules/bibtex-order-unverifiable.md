# bibtex-order-unverifiable

**Порядок записей библиографии задан стилем BibTeX и по исходникам не проверяется.**

| | |
|---|---|
| Категория | Источники и ссылки на них |
| Источник требования | стандарт |
| Пункты | ГОСТ 7.32-2017 п. 6.16<br>ГОСТ Р 2.105-2019 п. 6.4.2 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--info">info</span> |
| Объявлено в | `nk.rules.bibliography.bibliography_bibtex` |
| Фикстуры | `tests/fixtures/bibtex-order-unverifiable/` |
| Автоисправление | нет |

Сообщает, что список источников собирается BibTeX: порядок записей задаёт
стиль оформления, и по исходникам он не проверяется. Находка выдаётся один
раз на документ и только если списка в исходнике нет.

## Почему это нарушение

Это не нарушение, а граница применимости инструмента: порядок появления
ссылок обеспечивается выбором стиля, а проверить его можно лишь по
собранному документу.

## Как исправить

Убедиться, что выбран стиль с порядком по появлению ссылок — например
`unsrt`. Если порядок проверяется другим способом, правило отключается
профилем.

## Нарушение

```latex
Методика изложена в \cite{ivanov}.

\bibliographystyle{gost2008}
\bibliography{sources}
```

## Как правильно

```latex
Методика изложена в \cite{ivanov}.

\begin{thebibliography}{9}
  \bibitem{ivanov} Иванов И. И. Методика измерений. Москва, 2020. 120 с.
\end{thebibliography}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["bibtex-order-unverifiable"]

[rules."bibtex-order-unverifiable"]
severity = "info"
```
