# enumeration-label

**Элемент перечисления обозначен не по форме.**

| | |
|---|---|
| Категория | Перечисления |
| Источник требования | стандарт |
| Пункты | ГОСТ 7.32-2017 п. 6.4.6<br>ГОСТ Р 2.105-2019 п. 6.7.4 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--error">error</span> |
| Объявлено в | `nk.rules.enumerations.enumeration_label` |
| Фикстуры | `tests/fixtures/enumeration-label/` |
| Автоисправление | да, ключом `--fix` |

Проверяет форму обозначения, заданного явно — `\item[а)]` и подобных:
маркер, алфавит буквы, её регистр и знак после обозначения. Перечисление
без явных обозначений набирает маркеры средствами класса документа, и по
исходникам о них судить нельзя. Какая именно буква допустима, проверяет
отдельное правило того же пункта.

## Почему это нарушение

Перед каждым элементом перечисления ставят тире. Если на элементы нужно
ссылаться, вместо тире печатают строчную букву русского алфавита или
арабскую цифру, после которых ставят скобку: точка после обозначения
делает элемент похожим на пункт рубрикации.

## Как исправить

Привести обозначение к принятой форме: `\item[--]` заменить на маркер,
принятый источником требований, `\item[1.]` — на `\item[1)]`.

Маркер и допустимые алфавиты задаются параметрами: ГОСТ 7.32 требует тире
и русских букв, ГОСТ Р 2.105 — дефиса и русских либо латинских.

## Параметры

| Параметр | По умолчанию |
|---|---|
| `alphabets` | `["cyrillic"]` |
| `marker` | `"—"` |

## Нарушение

```latex
\begin{enumerate}
  \item[а.] удалённый заказ;
  \item[b)] виртуальная справочная служба;
  \item[В)] виртуальный читальный зал;
  \item[4.] электронная доставка документов.
\end{enumerate}

\begin{itemize}
  \item[--] первый элемент перечисления;
  \item[-] второй элемент перечисления.
\end{itemize}
```

## Как правильно

```latex
\begin{enumerate}
  \item[а)] удалённый заказ;
  \item[б)] виртуальная справочная служба;
  \item[в)] виртуальный читальный зал.
\end{enumerate}

\begin{enumerate}
  \item[1)] первый этап работы;
  \item[2)] второй этап работы.
\end{enumerate}

\begin{itemize}
  \item[—] элемент перечисления, помеченный тире;
  \item элемент без явного обозначения: маркер задаёт класс документа.
\end{itemize}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["enumeration-label"]

[rules."enumeration-label"]
severity = "info"

[rules."enumeration-label".params]
alphabets = ["cyrillic"]
```
