# bibitem-prescribed-spacing

**У знака предписанной пунктуации нет пробела.**

| | |
|---|---|
| Категория | Источники и ссылки на них |
| Источник требования | стандарт |
| Пункты | ГОСТ Р 7.0.100-2018 п. 4.6.5 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--error">error</span> |
| Объявлено в | `nk.rules.bibliography.bibitem_prescribed_spacing` |
| Фикстуры | `tests/fixtures/bibitem-prescribed-spacing/` |
| Автоисправление | да, ключом `--fix` |

Проверяет пробелы у знаков предписанной пунктуации в описании
источника: `:` `;` `/` `//` `=` отделяются пробелом с обеих сторон, точка
и запятая — только справа.

Лишние пробелы правило не считает нарушением: в наборе они всё равно
сходятся в один. Точку и запятую правило разбирает только там, где за ними
сразу идёт текст: «Malashenko, B., Zemerov» и «[и др.].» набирают слитно,
потому что рядом стоит другой знак, а не слово. Знак пропуска — многоточие
(п. 4.6.8) — правило не трогает: у него пробелы с обеих сторон.

Внутри сетевого адреса и идентификатора DOI знаки не разбираются, между
цифрами тоже — там точка и двоеточие принадлежат дате, номеру или дроби.
Двоеточие после слова из параметра `labels` — часть примечания
(«URL: адрес»), а не знак областей описания.

Записи разбираются только в списке, набранном в исходнике: у списка,
собираемого BibTeX, описаний в `.tex` нет.

Знак «плюс» и скобки правило не проверяет: плюс в описаниях чаще часть
заглавия, чем сведения о сопроводительном материале, а скобка (п. 4.6.6)
почти всегда соседствует с грамматическим знаком, от которого предписанный
по исходнику не отличить.

## Почему это нарушение

Предписанный знак опознаёт область и элемент описания, и опознают его по
пробелам: без них двоеточие в «Название: подзаголовок» ничем не отличается
от двоеточия внутри заглавия. Для того знаки и отделяют пробелом в один
печатный знак до и после — кроме точки и запятой, у которых пробел только
после.

## Как исправить

Поставить пробел: `Название: подзаголовок` → `Название : подзаголовок`,
`Иванов И. И.,2020` → `Иванов И. И., 2020`.

## Параметры

| Параметр | По умолчанию |
|---|---|
| `labels` | `["URL", "DOI", "дата обращения", "дата публикации", "дата обновления", "дата пересмотра", "режим доступа"]` |

## Нарушение

```latex
Методика изложена в \cite{ivanov}.

\begin{thebibliography}{9}
  \bibitem{ivanov} Иванов, И.~И. Методика измерений: пособие /И.~И. Иванов. – Москва :Наука, 2020.
  \bibitem{petrov} Петров, П.~П. Обработка результатов // Вестник МГТУ. – 2021. – № 4 . – С. 12--20.
  \bibitem{sidorov} Сидоров, С.~С. Поправки к методике. – Москва : Наука,2022. – 80~с.
\end{thebibliography}
```

## Как правильно

```latex
Методика изложена в \cite{ivanov}.

\begin{thebibliography}{9}
  \bibitem{ivanov} Иванов, И.~И. Методика измерений : пособие /
  И.~И. Иванов, П.~П. Петров. – Москва : Наука, 2020. – 250~с.
  \bibitem{petrov} Петров, П.~П. Обработка результатов // Вестник МГТУ. – 2021. –
  № 4. – С. 12--20. – DOI: 10.1234/vestnik.2021.04.002.
  \bibitem{site} Библиотека : официальный сайт. – Москва, 2024. –
  URL: https://www.rsl.ru/catalog?year=2024 (дата обращения: 04.09.2026).
  \bibitem{team} Методика ... измерений / Иванов, И.~И. [и др.]. –
  Москва : Наука, 2020. – 120~с.
  \bibitem{en} USER : Universal Sentence Encoder / Malashenko, B., Zemerov, A. –
  Hugging Face, 2024. – URL: \url{https://huggingface.co/deepvk}.
\end{thebibliography}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["bibitem-prescribed-spacing"]

[rules."bibitem-prescribed-spacing"]
severity = "info"

[rules."bibitem-prescribed-spacing".params]
labels = ["URL", "DOI", "дата обращения", "дата публикации", "дата обновления", "дата пересмотра", "режим доступа"]
```
