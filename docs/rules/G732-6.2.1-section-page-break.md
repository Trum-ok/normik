# G732-6.2.1-section-page-break

**Раздел не начинается с новой страницы.**

| | |
|---|---|
| Категория | Заголовки и рубрикация |
| Пункт ГОСТ 7.32-2017 | 6.2.1 |
| Уровень по умолчанию | `error` |
| Объявлено в | `nk.rules.headings.section_page_break` |
| Фикстуры | `tests/fixtures/G732-6.2.1-section-page-break/` |
| Автоисправление | да, ключом `--fix` |

Проверяет разрыв страницы перед рубрикой уровня раздела — и структурного
элемента, и раздела основной части. Приложения проверяет отдельное правило
п. 6.17.3. Рубрика в начале файла пропускается: разрыв мог остаться в файле,
который её включает.

Рубрика, которая открывает страницу сама, разрыва не требует: `\chapter`,
а также макрос шаблона, если `\newpage` вписан внутрь его определения.
Макрос, объявленный в `.sty`, парсеру не виден — такие команды перечисляют
параметром `breaking_commands`.

Параметр `structural_only` сужает правило до структурных элементов: разделы
основной части с новой страницы требует не всякий источник требований.

## Почему это нарушение

Каждый структурный элемент и каждый раздел основной части начинают
с новой страницы: раздел, начатый посреди листа, читается как продолжение
предыдущего.

## Как исправить

Добавить `\newpage` перед заголовком раздела.

## Параметры

| Параметр | По умолчанию |
|---|---|
| `breaking_commands` | `['chapter']` |
| `structural_only` | `False` |

## Нарушение

```latex
\begin{document}

\section*{ВВЕДЕНИЕ}

Постановка задачи и цель работы.

\section{Выбор направления исследований}

Обзор существующих решений.

\subsection{Сравнение подходов}

Подраздел с новой страницы не начинают.

\newpage
\section{Теоретические исследования}

Модель процесса.

\section*{ЗАКЛЮЧЕНИЕ}

Краткие выводы по результатам работы.

\end{document}

Хвост абзаца. \section{Раздел в строке с текстом}
Текст раздела.
```

## Как правильно

```latex
\newcommand{\element}[1]{\newpage\section*{\centering #1}}

\begin{document}

\section*{РЕФЕРАТ}

Отчёт 45 с., 1 кн., 3 рис., 2 табл., 12 источн., 1 прил.

\newpage
\section*{ВВЕДЕНИЕ}

Постановка задачи и цель работы.

\clearpage
\section{Выбор направления исследований}

Обзор существующих решений.

\subsection{Сравнение подходов}

Подраздел с новой страницы не начинают.

\element{ЗАКЛЮЧЕНИЕ}

Разрыв, вписанный в макрос шаблона, снаружи повторять не нужно.

\newpage
\section*{ПРИЛОЖЕНИЕ А}

Разрыв перед приложением проверяет правило п. 6.17.3.

\section*{ПРИЛОЖЕНИЕ Б}

Второе приложение — тоже не наше правило.

\end{document}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["G732-6.2.1-section-page-break"]

[rules."G732-6.2.1-section-page-break"]
severity = "info"

[rules."G732-6.2.1-section-page-break".params]
breaking_commands = ['chapter']
```
