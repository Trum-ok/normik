# bibitem-final-dot

**Библиографическое описание не заканчивается точкой.**

| | |
|---|---|
| Категория | Источники и ссылки на них |
| Источник требования | стандарт |
| Пункты | ГОСТ Р 7.0.100-2018 п. 4.6.1 |
| Уровень по умолчанию | <span class="nk-severity nk-severity--error">error</span> |
| Объявлено в | `nk.rules.bibliography.bibitem_final_dot` |
| Фикстуры | `tests/fixtures/bibitem-final-dot/` |
| Автоисправление | да, ключом `--fix` |

Проверяет, что описание источника закрыто точкой. Записи разбираются
только в списке, набранном в исходнике: у списка, собираемого BibTeX,
описаний в `.tex` нет.

## Почему это нарушение

Точка в конце — предписанный знак, а не грамматический: он закрывает
описание целиком и отделяет его от следующего. Без него две соседние
записи в наборе сливаются в одну.

## Как исправить

Поставить точку после последнего элемента описания: `... — 250 с.`

## Нарушение

```latex
Методика изложена в \cite{ivanov}, поправки — в \cite{petrov}.

\begin{thebibliography}{9}
  \bibitem{ivanov} Иванов, И.~И. Методика измерений. – Москва : Наука, 2020. – 120~с
  \bibitem{petrov} Петров, П.~П. Обработка результатов : учебное пособие /
  П.~П. Петров. – Москва : Наука, 2021. – 200~с
  \bibitem{site} Библиотека : официальный сайт. – Москва, 2024. –
  URL: \url{https://www.rsl.ru/}
\end{thebibliography}
```

## Как правильно

```latex
Методика изложена в \cite{ivanov}, поправки — в \cite{petrov},
источник — в \cite{site}.

\begin{thebibliography}{9}
  \bibitem{ivanov} Иванов, И.~И. Методика измерений. – Москва : Наука, 2020. – 120~с.
  \bibitem{petrov} Петров, П.~П. Обработка результатов : учебное пособие /
  П.~П. Петров. – Москва : Наука, 2021. – 200~с.
  \bibitem{site} Российская государственная библиотека : официальный сайт. –
  Москва, 2024. – URL: https://www.rsl.ru/ (дата обращения: 04.09.2026).
\end{thebibliography}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["bibitem-final-dot"]

[rules."bibitem-final-dot"]
severity = "info"
```
