# evaluative-word

**Свойство названо оценкой, а не показателем.**

| | |
|---|---|
| Категория | Изложение текста |
| Источник требования | положение вуза |
| Пункты | — |
| Уровень по умолчанию | <span class="nk-severity nk-severity--warning">warning</span> |
| Объявлено в | `nk.rules.text.evaluative_word` |
| Фикстуры | `tests/fixtures/evaluative-word/` |
| Автоисправление | нет |

Ищет оценочные слова: «хорошо», «удобный», «эффективный», «современный».
Формулы, листинги, список источников и рубрикация не проверяются.

Слово, стоящее в термине, замечанием не считается: «эффективное значение
напряжения», «отличная от нуля величина», «простые числа», «качественный
анализ». Перечень терминов правило знает, а тему работы, где оценка
закреплена утверждённым названием, обходит вместе с рубрикацией.

Слово, которое на кафедре считают термином, добавляется параметром `allow`
началом слова: `allow = ["эффективн", "оптимальн"]`. Проверку заголовков
включает параметр `headings`: по умолчанию правило их не трогает, потому что
«Современные методы решения задачи» — обычное название обзорного раздела.

Числа замечание не снимают: «программа объёмом 300 строк работает хорошо»
так и осталось без показателя. Мера, которой число помогает, — забота
правила `vague-quantifier`.

## Почему это замечание

Оценка не проверяется: «хорошо» у автора и у рецензента разное, а сравнить
их нечем. Отчёт сообщает, что измерено и чему равно, — тогда результат можно
воспроизвести и оспорить.

## Как исправить

Назвать показатель, его значение и условия измерения: «работает хорошо» →
«время отклика не превышает 40 мс при 100 запросах в секунду».

!!! note

    Ни один стандарт этого не требует: источник — положение вуза либо методические указания кафедры. Название источника и пункт объявляет [профиль](../profiles.md#стандарт-и-свой-источник-требований).

## Параметры

| Параметр | По умолчанию |
|---|---|
| `allow` | `[]` |
| `headings` | `false` |

## Нарушение

```latex
Разработанная программа работает хорошо.
Выбран современный и надёжный протокол передачи данных.
Интерфейс получился удобным, а работать с ним просто.
Предложенный алгоритм показал лучшие результаты.
```

## Как правильно

```latex
\section{Современные методы решения задачи}

Программа обрабатывает файл размером 1~Гбайт за 12~с.
Протокол выбран по времени доставки: 40~мс против 120~мс у аналога.
Эффективность метода оценивается по числу итераций.
Эффективное значение напряжения равно 220~В.
Матрица системы плохо обусловлена, поэтому применена регуляризация.
Простые числа отбираются решетом Эратосфена.
Проведён качественный анализ состава образца.
В выборку попадает величина, отличная от нуля.
Современное состояние вопроса рассмотрено в первом разделе.

\begin{thebibliography}{9}
\bibitem{sort} Смит Дж. Эффективные алгоритмы сортировки. --- М.: Мир, 2019. --- 320~с.
\end{thebibliography}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["evaluative-word"]

[rules."evaluative-word"]
severity = "info"

[rules."evaluative-word".params]
allow = []
```
