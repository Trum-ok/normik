# vague-quantifier

**Мера приведена без числа.**

| | |
|---|---|
| Категория | Изложение текста |
| Источник требования | положение вуза |
| Пункты | — |
| Уровень по умолчанию | <span class="nk-severity nk-severity--warning">warning</span> |
| Объявлено в | `nk.rules.text.vague_quantifier` |
| Фикстуры | `tests/fixtures/vague-quantifier/` |
| Автоисправление | нет |

Ищет меру без числа: «значительно вырос», «существенно меньше», «довольно
много». Формулы, листинги, список источников и рубрикация не проверяются.

Замечание снимается, когда величина названа в том же предложении: число,
диапазон, доля или ссылка на таблицу, рисунок либо формулу, где значение
приведено. «Быстродействие выросло значительно, с 120 до 40 мс» — мера
подкреплена, замечания нет. Проверку числом выключает параметр
`require_number`: тогда мера считается замечанием всегда.

Слово, которое на кафедре считают термином, добавляется параметром `allow`
началом слова. Проверку заголовков включает параметр `headings`.

## Почему это замечание

«Значительно» само по себе шкалы не имеет: во сколько раз и с чего до чего —
из текста не следует, а вывод о результате читатель делает по числу.

## Как исправить

Привести значение рядом со словом или вместо него: «значительно выросло» →
«выросло на 35 %», «существенно меньше» → «меньше в 4 раза».

!!! note

    Ни один стандарт этого не требует: источник — положение вуза либо методические указания кафедры. Название источника и пункт объявляет [профиль](../profiles.md#стандарт-и-свой-источник-требований).

## Параметры

| Параметр | По умолчанию |
|---|---|
| `allow` | `[]` |
| `headings` | `false` |
| `require_number` | `true` |

## Нарушение

```latex
Быстродействие значительно выросло после оптимизации.
Погрешность существенно меньше, чем у прототипа.
Обучение модели занимает довольно много времени.
Испытания заняли 12~ч. Метод весьма чувствителен к выбору шага.
```

## Как правильно

```latex
Быстродействие выросло на 35~\% после оптимизации.
Время отклика уменьшилось значительно,
с 120 до 40~мс.
Достаточным условием сходимости является липшицевость правой части.
Данных достаточно для проверки гипотезы.
Достаточно рассмотреть два предельных случая.
Система существенно нелинейна, поэтому линеаризация неприменима.
Число итераций сокращается заметно, см. таблицу~\ref{tab:iterations}.
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["vague-quantifier"]

[rules."vague-quantifier"]
severity = "info"

[rules."vague-quantifier".params]
allow = []
```
