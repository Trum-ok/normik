# first-person-pronoun

**Текст изложен от первого лица: местоимение.**

| | |
|---|---|
| Категория | Изложение текста |
| Источник требования | положение вуза |
| Пункты | — |
| Уровень по умолчанию | <span class="nk-severity nk-severity--warning">warning</span> |
| Объявлено в | `nk.rules.text.first_person_pronoun` |
| Фикстуры | `tests/fixtures/first-person-pronoun/` |
| Автоисправление | нет |

Ищет местоимения первого лица во всех падежах, вместе с притяжательными.
Формулы, буквальные вставки и листинги не проверяются.

Авторское «мы» правило по умолчанию не трогает: часть руководителей его
требует. Включается параметром `plural`.

Безличного изложения ни один стандарт не требует: это требование положений
вузов и методических указаний. Предъявляют его почти везде, поэтому правило
включено по умолчанию.

## Почему это замечание

Отчёт излагают безлично: сообщается, что сделано, а не кем. «Я настроил
стенд» и «стенд настроен» несут одно и то же, но первое переводит текст
из отчёта в рассказ о себе.

## Как исправить

Переписать предложение безличной или страдательной конструкцией: «мною
выполнен расчёт» → «выполнен расчёт», «в моей программе» → «в программе».

!!! note

    Ни один стандарт этого не требует: источник — положение вуза либо методические указания кафедры. Название источника и пункт объявляет [профиль](../profiles.md#стандарт-и-свой-источник-требований).

!!! note

    Готовое исправление правило не предлагает: оно принципиально неоднозначно.

## Параметры

| Параметр | По умолчанию |
|---|---|
| `plural` | `false` |

## Нарушение

```latex
Я настроил стенд и снял показания.
Мне удалось повторить эксперимент трижды.
Расчёт выполнен в моей программе.
Полученные значения я свёл в таблицу.
```

## Как правильно

```latex
Стенд настроен, показания сняты.
Эксперимент удалось повторить трижды.
Расчёт выполнен в программе, написанной для этой задачи.
Полученные значения сведены в таблицу.
Протокол измерений вынесен в ПРИЛОЖЕНИЕ Я.
Ниже мы рассмотрим устойчивость системы.
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["first-person-pronoun"]

[rules."first-person-pronoun"]
severity = "info"

[rules."first-person-pronoun".params]
plural = false
```
