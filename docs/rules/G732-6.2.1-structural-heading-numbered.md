# G732-6.2.1-structural-heading-numbered

**Заголовок структурного элемента пронумерован.**

| | |
|---|---|
| Пункт ГОСТ 7.32-2017 | 6.2.1 |
| Уровень по умолчанию | `error` |
| Объявлено в | `nk.rules.layout.structural_heading_numbered` |
| Фикстуры | `tests/fixtures/G732-6.2.1-structural-heading-numbered/` |

Ищет заголовки структурных элементов, заданные нумерованной формой команды
раздела.

## Почему это нарушение

Порядковые номера имеют только разделы основной части. Пронумерованное
введение сдвигает нумерацию всех последующих разделов и попадает в содержание
как раздел 1.

## Как исправить

Использовать ненумерованную форму команды — со звёздочкой — и добавить элемент
в содержание вручную, если этого требует класс документа.

## Нарушение

```latex
\section{ВВЕДЕНИЕ}

\section{ЗАКЛЮЧЕНИЕ}

\section{СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ}
```

## Как правильно

```latex
\section*{ВВЕДЕНИЕ}

\section*{ЗАКЛЮЧЕНИЕ}

\section*{СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ}

Разделы основной части, наоборот, нумеруются.

\section{Выбор направления исследований}

\subsection{Методы решения задач}
```
