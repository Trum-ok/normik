# NK-STYLE-dash

**Дефис вместо тире.**

| | |
|---|---|
| Пункт ГОСТ 7.32-2017 | вне стандарта |
| Уровень по умолчанию | `info` |
| Объявлено в | `nk.rules.typography.text_dash` |
| Фикстуры | `tests/fixtures/NK-STYLE-dash/` |
| Автоисправление | да, ключом `--fix` |

Находит одиночный дефис там, где по смыслу стоит тире.

## Почему это замечание

ГОСТ 7.32-2017 знаков препинания не регулирует, но нормоконтроль обращает
на это внимание: дефис и тире — разные знаки, и в наборе они выглядят
по-разному.

## Как исправить

Заменить дефис на тире. Последовательности `--` и `---` LaTeX превращает
в тире сам, их правило не трогает. В формулах, листингах и таблицах дефис
не проверяется: там это знак вычитания или содержимое ячейки.

## Нарушение

```latex
Нормоконтроль - это проверка соблюдения требований стандарта.
```

## Как правильно

```latex
Нормоконтроль — это проверка соблюдения требований стандарта.

Последовательности LaTeX правило не трогает: диапазон 10--15 с. и тире --- вот так.

Дефис внутри слова тоже не нарушение: научно-исследовательская работа.

В формуле знак минуса дефисом не считается: $a - b = c$.

Выключная формула проверяется так же, как строчная:

\begin{equation}
	\sum_{x_p, x_q \in C_i} \| x_p - x_q \|_2,
	\label{intra}
\end{equation}

\[
	y - z = 0
\]

\begin{tabular}{ll}
  а & - \\
\end{tabular}

\section*{ТЕРМИНЫ И ОПРЕДЕЛЕНИЯ}

нормоконтроль - проверка соблюдения норм, об этом сообщает правило 6.14

Буквальные вставки типографике не подчиняются: \verb|список - массив|,
\lstinline[language=C]|char - тип|, \texttt{make - all}, \path{/usr - share}.
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["NK-STYLE-dash"]

[rules."NK-STYLE-dash"]
severity = "info"
```
