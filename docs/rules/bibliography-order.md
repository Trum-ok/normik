# bibliography-order

**Записи списка источников идут не в порядке появления ссылок.**

| | |
|---|---|
| Категория | Источники и ссылки на них |
| Пункты | ГОСТ 7.32-2017 п. 6.16, ГОСТ Р 2.105-2019 п. 6.4.2 |
| Уровень по умолчанию | `error` |
| Объявлено в | `nk.rules.bibliography.bibliography_order` |
| Фикстуры | `tests/fixtures/bibliography-order/` |
| Автоисправление | нет |

Сопоставляет порядок записей в списке источников с порядком первых ссылок
на них в тексте. Записи, на которые ссылок нет, порядок не нарушают —
их разбирает отдельное правило.

## Почему это нарушение

Сведения об источниках располагают в порядке появления ссылок на них
в тексте отчёта: номер ссылки должен возрастать по мере чтения.

## Как исправить

Переставить записи `\bibitem` в порядке первых ссылок либо перестроить
изложение так, чтобы источники упоминались по порядку.

## Нарушение

```latex
Методика изложена в \cite{ivanov}, обработка результатов — в \cite{petrov}.

\begin{thebibliography}{9}
  \bibitem{petrov} Петров П. П. Обработка результатов. Москва, 2021. 200 с.
  \bibitem{ivanov} Иванов И. И. Методика измерений. Москва, 2020. 120 с.
\end{thebibliography}
```

## Как правильно

```latex
Методика изложена в \cite{ivanov}, обработка результатов — в \cite{petrov}.

\begin{thebibliography}{9}
  \bibitem{ivanov} Иванов И. И. Методика измерений. Москва, 2020. 120 с.
  \bibitem{petrov} Петров П. П. Обработка результатов. Москва, 2021. 200 с.
\end{thebibliography}
```

## Настройка

Отключить правило либо изменить его уровень [профилем](../profiles.md):

```toml
disable = ["bibliography-order"]

[rules."bibliography-order"]
severity = "info"
```
